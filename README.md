





# Working with Strings and Numbers

# 🧮 Repository: `working-with-strings-and-numbers`

Welcome to **working-with-strings-and-numbers**, part of the [practice-python-for-beginners](https://github.com/practice-python-for-beginners) series.

**Goal:**  
Teach beginners how to work with **text (strings)** and **numbers (integers, floats)**, including formatting, concatenation, arithmetic, conversions, and built-in functions.

This repository helps beginners understand **string** and **numeric** data handling in Python.

---

## 📚 Topics Covered
- String creation and manipulation  
- String formatting (f-strings, concatenation, `format()`)  
- Integer and floating-point arithmetic  
- Rounding, absolute values, and modulus  
- Type conversions between strings and numbers

## ⚙️ Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/practice-python-for-beginners/working-with-strings-and-numbers.git
   cd working-with-strings-and-numbers
   ```

2. (Optional) Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate   # Windows: venv\Scripts\activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Run tests:
   ```bash
   pytest
   ```
